# 实验阶段目录

| 目录 | 范围 |
|---|---|
| `stage00_baselines/` | 课程期间的 Graph、重叠调度和 TP 基线实验 |
| `stage01_measurement/` | 回放、指标、时间线、记录开销及输出差异调查 |
| `stage02_prefill_interference/` | 长 prefill 干扰 decode 的预算对照；不改调度策略 |
| `stage03_scheduling/` | 等待阈值公平调度、优先级对照、决策日志与生命周期验证 |
| `stage04_system_evaluation/` | ShareGPT 数据准备、六类负载、三档压力与独立预算确认 |
| `stage05_correctness_attribution/` | 已完成：输出分歧定位、生命周期修复与验证、Nsight 性能归因 |

每阶段包含自己的入口、说明、报告及证据。阶段二复用阶段一的测量工具，避免重复实现指标。后续阶段按相同命名方式添加。`runs/` 保存本地生成产物，审核选定证据后纳入版本控制。

原定六阶段以根目录 [实验计划](../实验计划.md) 为准：

1. 建立测量工具。
2. 复现长 prefill 干扰。
3. 实现公平调度策略（等待时间阈值是主要改动）。
4. 系统评估（固定预算对照后再扫预算）。
5. 正确性与性能归因。
6. 整理成面试项目。

阶段零为此前课程实验，不替代以上六阶段。
